# 🌐 Portfolio Landing Page

A modern and responsive landing page built with HTML and CSS and basic Javascript. The project focuses on clean design, responsive layouts, and an engaging user experience across desktop and mobile devices.

## 🚀 Features

- Responsive design
- Modern user interface
- Mobile-friendly layout
- Clean and organized code structure
- Smooth user experience

## 🛠️ Technologies Used

- HTML5
- CSS3
- Javascript
